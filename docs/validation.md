# V0.1 验证记录

日期：2026-10-20。此记录是本次交付验证结果，不代表商业代理 SLA 或目标网站长期可用性。

## 已完成

- TypeScript 编译与格式检查通过。
- 6 项自动测试通过，使用真实 Chromium 和受控测试站点。
- HTTP 用户名/密码代理、SOCKS5 用户名/密码代理均通过 HTTP 转发和 CONNECT 隧道测试。
- 错误鉴权、代理端口不可达时，目标服务器未收到直连请求。
- 自定义 UA、页面视口、触控、独立 Cookie 会话验证通过。
- 输入/点击、确认框、多标签页、iframe、截图、下载文件内容、上传文件验证通过。
- MCP stdio 工具发现（24 个工具）、操作查询、产物传输、同 principal 断线重连及跨 principal 访问拒绝验证通过。
- Docker 镜像构建成功；Linux arm64 容器以内置非 root 用户运行，浏览器可启动，MCP 端到端调用通过。
- 容器实际 HTTPS 导航及页面快照通过。
- 容器正常重启、SIGKILL 后再次启动均恢复管理进程健康检查。
- npm 依赖审计未报告已知漏洞（含开发依赖）。

## 尚未覆盖

- 用户 Webshare 真实节点的质量、国家识别及 SLA。
- 生产网站完整业务回归、移动真机、Safari 引擎。
- 严格网络层无旁路证明、恶意站点隔离、浏览器 sandbox/seccomp 部署。
- 长时间负载及资源容量测试。

GitHub Actions 包含 Linux runner 自动测试及 Docker 构建/运行验证；具体执行结果以仓库 Actions 为准。
